# Site de révision CEJM — Économie (BTS SIO 1re année)

## Fichiers
- `index.html` : structure du site et navigation.
- `style.css` : mise en page responsive.
- `questions.js` : les 60 questions, réponses et explications.
- `app.js` : fonctionnement des quiz, progression et flashcards.

## Lancer le site
1. Décompresse le dossier.
2. Garde les quatre fichiers dans le même dossier.
3. Double-clique sur `index.html` pour ouvrir le site dans ton navigateur.

Aucune installation n'est nécessaire. Une connexion Internet peut être utilisée pour charger la police Google Fonts ; le site reste utilisable sans elle.

## Organisation
- 3 niveaux de 20 questions : bases, compréhension, approfondissement.
- Les 60 questions des QCM sont reprises à l'identique dans les flashcards.
- Chaque QCM affiche une correction et une explication.
- La progression, les réponses et les cartes maîtrisées sont conservées pendant la session ouverte. Elles ne sont pas sauvegardées après fermeture/rechargement du navigateur.

## Périmètre du cours
Contenu élaboré à partir de la section « Notion de bases » du fichier OneNote fourni, en retenant les notions économiques : marché, offre/demande, prix d'équilibre, concurrence, agents économiques, circuit économique, banque/financement, échanges extérieurs et externalités.
